
Old-Notepad is a simple batch script that helps restore or launch the classic Notepad experience on modern versions of Windows.

Features
Easy setup with a single batch file
Lightweight
No additional software required
Made for users who prefer the classic Notepad
Installation
Download or clone this repository.
Run oldnotepadsetup.bat.
Follow the prompts shown on screen.
Files
File	Description
oldnotepadsetup.bat	Setup script for Old-Notepad
Requirements
Windows
Administrator privileges may be required
